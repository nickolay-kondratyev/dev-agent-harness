## Problem
Callback scripts (callback_shepherd.signal.sh, callback_shepherd.query.sh) were referenced by bare script name in agent instructions, relying on PATH to resolve them. In tmux sessions, PATH modifications from ClaudeCodeAdapter were not always inherited by agent subprocesses, causing callback failures.

## Solution
Thread CallbackScriptsDir (which holds the validated directory path) through the instruction assembly pipeline. All instruction sections (CallbackHelp, FeedbackItem, SelfCompactionInstructionBuilder) now render the full absolute path.

## Files changed
- CallbackScriptsDir.kt: added signalScriptPath and queryScriptPath properties
- InstructionSection.kt: CallbackHelp and FeedbackItem accept full paths
- ContextForAgentProvider.kt / ContextForAgentProviderImpl.kt: accept CallbackScriptsDir
- SelfCompactionInstructionBuilder.kt: build() takes callbackSignalScriptPath
- PartExecutorImpl.kt / InnerFeedbackLoop.kt: thread paths through deps
- ContextInitializer.kt: Infra includes CallbackScriptsDir
- ProductionPartExecutorFactoryCreator.kt: extracted buildGitCommitStrategy() helper
- 16 test files updated
