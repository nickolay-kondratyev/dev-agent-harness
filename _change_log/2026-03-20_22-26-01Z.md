## Problem
Callback scripts (callback_shepherd.signal.sh, callback_shepherd.query.sh) were referenced by bare script name in agent instructions, relying on PATH to resolve them. In tmux sessions, PATH modifications from ClaudeCodeAdapter were not always inherited by agent subprocesses, causing callback failures.

## Solution
Thread `CallbackScriptsDir` through the full dependency graph so all agent-facing code uses absolute paths.

## Changes
- `CallbackScriptsDir.kt`: added `signalScriptPath` and `queryScriptPath` properties
- `InstructionSection.kt`: `CallbackHelp` and `FeedbackItem` render full paths
- `ContextForAgentProvider/Impl`: accept `CallbackScriptsDir`, thread to instruction sections
- `SelfCompactionInstructionBuilder`: `build()` takes full path
- `AckedPayloadSender`: `wrapPayload()` uses full path in ACK commands
- `SubPartConfigBuilder`: bootstrap message uses full path
- `PartExecutorDeps`, `InnerFeedbackLoopDeps`, `Infra`: carry `CallbackScriptsDir`
- PATH export in `ClaudeCodeAdapter` kept as defense-in-depth
- 20+ test files updated
